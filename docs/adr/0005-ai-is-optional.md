# ADR 0005: AI is optional infrastructure

**Status:** Accepted

## Decision

Generative AI is not required for collection, durable storage, provenance, exact search or basic semantic retrieval. AI providers are introduced behind interfaces only where they add measurable value.

## Consequences

- the application remains useful offline and without paid services;
- local and cloud models can be replaced independently;
- summaries never become the only retained representation of source material.
