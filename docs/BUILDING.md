# Building

## Toolchain

The project pins dependency/plugin versions in `gradle/libs.versions.toml` and the build currently uses:

- JDK 17;
- official Gradle Wrapper 9.6.0;
- Android Gradle Plugin 9.4.0;
- compile SDK 37 (Android 17 APIs);
- target SDK 36;
- SDK Build Tools 36.0.0;
- minimum SDK 26.

This combination is intentional. AGP 9.4 supports API 37 and requires/defaults to Gradle 9.6.0, JDK 17 and Build Tools 36.0.0. `compileSdk = 37` is required by the current Android dependency line; `targetSdk = 36` remains a separate runtime-behavior decision and is not changed implicitly by dependency updates.

AGP 9 uses built-in Kotlin for Android modules. Pure JVM modules use the explicit Kotlin JVM plugin.

## Gradle Wrapper integrity

A fresh checkout must not require a separately installed Gradle distribution. Use the committed wrapper:

```bash
./gradlew --version
```

The wrapper was generated by Gradle 9.6.0. Integrity is pinned in two ways:

- `gradle/wrapper/gradle-wrapper.properties` contains the SHA-256 of `gradle-9.6.0-bin.zip`;
- CI verifies the committed `gradle-wrapper.jar` SHA-256 before executing the build.

Do not hand-edit or replace the wrapper JAR. Regenerate it with the official Gradle `wrapper` task and update the documented/checksummed values together.

## Local prerequisites

Install:

- JDK 17;
- Android SDK platform 37;
- Android SDK Build Tools 36.0.0;
- Android platform tools.

No system Gradle installation is required.

## Clean-checkout verification

From the repository root:

```bash
./gradlew --version
./gradlew test --stacktrace
./gradlew lint --stacktrace
./gradlew assembleDebug --stacktrace
```

The debug application id is `io.github.go0dboy.articlenavigator.dev`; the release/base id remains `io.github.go0dboy.articlenavigator`.

## CI quality gates

GitHub Actions performs the same wrapper-based build on a fresh checkout and additionally verifies:

- wrapper JAR checksum;
- Gradle distribution checksum/version;
- committed Room schema consistency;
- unit/integration tests;
- Android lint;
- debug APK assembly and signature;
- debug APK package identity.

A successful workflow publishes `article-navigator-debug` as an installable APK artifact. No development phase is complete while any required gate is red.
